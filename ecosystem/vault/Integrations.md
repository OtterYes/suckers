# Integrations

What is real, what needs setup, and what is only planned. Nothing here assumes access to my accounts.

| Integration | Status | Notes |
|---|---|---|
| Local save + backups | **Real in M1** | JSON on my PC |
| Mock AI (demo mode) | **Real in M1** | Templates, $0, labeled |
| Export deliverables (`.md`, `.luau`) | **M1–M2** | To a folder I choose, which could be this vault |
| Real AI provider | **Needs setup (M4)** | I pick the provider and add an API key. **A ChatGPT subscription does not include API usage**, which is billed separately. |
| Roblox Studio via Rojo | **Planned (I use Rojo)** | The app would write `.luau` files into a Rojo project folder (after approval), and Rojo syncs them into Studio. Needs Rojo installed. The app never touches a live game. |
| Calendar `.ics` export | **Planned** | A file I import myself. No calendar login. |
| TikTok performance data | **Planned** | I export or paste numbers (CSV) and the Producer analyzes only that. No TikTok login. |
| Web or trend research | **Planned, off by default** | Only with a real connected search source. Otherwise agents say it isn't available. |
| Obsidian | **Real now** | This vault is plain Markdown in the repo. The app can later export deliverables into it. |
| School systems, TikTok account, Roblox account | **Not planned** | Would each need my explicit approval and a separate design |
