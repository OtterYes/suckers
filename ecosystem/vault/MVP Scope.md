# MVP Scope

The MVP is Milestones M1–M4 in [[Milestones]].

## In the MVP
- **Five agents:** [[Coordinator]] + [[Roblox Builder]] (full), plus [[Tutor]], [[Strategist]], and [[Producer]] (basic templates only)
- **Goal → plan → approve → run → review → done**, using the shared task structure in [[Data Model]]
- **[[Scheduling]]:** fixed commitments (school, sleep), deadlines, time estimates, a 7-day plan, a "Today" list, and warnings when something won't fit
- **Roblox lab deliverables:** game concept, core loop, prototype milestones, playtest plan, Luau drafts with client/server and exploit notes, and bug/feedback triage
- **3D world:** a central HQ and four areas around it, agents that show real states, click an agent to inspect it, and motion that matches real events ([[World Design]])
- **2D [[Dashboard]]:** board, today, schedule, deliverable editor, activity log
- **Local saving** with automatic backups
- **Demo mode** ($0) with clear labels
- **One real AI connection** for the Roblox Builder (M4), with a usage and cost meter, cancel button, limits, and the key kept out of the repo
- Agent memory I can inspect, edit, and delete (per project)

## Waits until after the MVP
- Real AI for the other agents
- Extra agents beyond the five
- Astra models replacing the simple shapes (these can start any time after M3; see [[Astra Model Specs]])
- Web or trend research (only with a real connected source, never invented)
- Syncing Luau into Roblox Studio (Rojo), calendar export, and importing TikTok analytics ([[Integrations]])
- Full Student and Business features (spaced practice tracking, budgets, pricing tools)
- Weather, day/night cycle, decorative wandering, sound
- Any online account access
